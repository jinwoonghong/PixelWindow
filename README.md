# PixelWindow 🐕

> 윈도우 데스크톱 오버레이 가상 애완동물 게임

![Version](https://img.shields.io/badge/version-0.1.0-blue)
![License](https://img.shields.io/badge/license-MIT-green)

## 소개

PixelWindow는 윈도우 환경에서 동작하는 데스크톱 오버레이 게임입니다. 귀여운 픽셀 강아지가 화면 위를 돌아다니며, 사용자의 활동에 반응하고 시간이 지남에 따라 성장합니다.

### 주요 기능

- 🖥️ **투명 오버레이**: 다른 작업을 방해하지 않는 투명한 오버레이 윈도우
- 🐶 **픽셀 강아지**: 귀여운 픽셀 아트 스타일의 강아지
- 🎮 **자동 AI**: 강아지가 스스로 돌아다니며 행동
- 🍖 **먹이 시스템**: 다양한 먹이가 랜덤하게 등장
- 📈 **성장 시스템**: 시간과 경험치에 따라 레벨업
- 💾 **자동 저장**: 게임 상태 자동 저장 및 복원
- 🎨 **커스터마이징**: 설정을 통한 게임 조정

## 설치 방법

### 실행 파일 (권장)

1. [Releases](https://github.com/yourname/pixelwindow/releases) 페이지에서 최신 버전 다운로드
2. 설치 프로그램 실행
3. PixelWindow 시작!

### 개발자 모드

```bash
# 저장소 클론
git clone https://github.com/yourname/pixelwindow.git
cd pixelwindow

# 의존성 설치
npm install

# 개발 모드 실행
npm run dev
npm start
```

## 사용 방법

### 기본 조작

- **강아지 클릭**: 메뉴 열기
- **트레이 아이콘**: 우클릭으로 빠른 메뉴 접근
- **종료**: 메뉴 또는 트레이에서 종료 선택

### 게임 플레이

1. 강아지는 자동으로 화면을 돌아다닙니다
2. 시간이 지나면 먹이가 랜덤하게 등장합니다
3. 강아지가 먹이를 먹으면 경험치를 획득합니다
4. 경험치가 쌓이면 레벨업하여 크기가 커집니다
5. 배고픔, 행복도, 에너지 상태를 관리하세요

### 통계 및 설정

- **통계**: 플레이 시간, 먹은 먹이 수 등 확인
- **설정**: 사운드, 이동 속도, 먹이 생성 주기 조정

## 기술 스택

- **Electron**: 데스크톱 애플리케이션 프레임워크
- **TypeScript**: 타입 안전성
- **HTML5 Canvas**: 렌더링
- **Webpack**: 번들링
